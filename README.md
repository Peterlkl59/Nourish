# Nourish PWA

A zero-backend, local-first calorie/protein tracker designed for iPhone Home Screen use.

## What works
- Editable calorie and protein targets
- Breakfast, Lunch, Snacks, Dinner and Drinks
- Add/edit/delete food on any date
- Gym toggle + duration
- Daily history
- Weekly average calories/protein based on logged days
- Weekly over/below target counts
- Weight + waist measurements, editable
- JSON backup/restore
- CSV food export
- Double-confirmed Delete All Data
- Offline-capable PWA
- Data stored locally on each device

## Important
The app stores data in browser local storage on the device. Export backups regularly. Clearing Safari/site data can remove local app data.

## Free hosting
Upload the contents of this folder to any static HTTPS host (for example GitHub Pages or Cloudflare Pages). HTTPS is required for the service worker/PWA behavior.

## iPhone install
Open the hosted URL in Safari, use Share, then Add to Home Screen. Launch Nourish from the new Home Screen icon.
